# EDA Insights

- Cleaned dataset contains 1,344,949 completed loans used for modeling.
- Overall observed default rate is 20.0%.
- Issue-year coverage spans 2007–2018.
- Highest yearly default rate: 2016 (23.3%).
- Lowest yearly default rate: 2009 (12.6%).
- Among the highest-volume purposes, 'small_business' has the highest observed default rate (29.7%).
